# 校园地图

## 进入与初始状态

用户从主导航进入地图后，左侧显示“苏州中学 · 本部校园”、页面标题“校园地图”和“循着书声，走进苏中”的引导语。地图以北向上、校园全景为初始视野，右侧或主区域显示方向罗盘、缩放控件、回到全景控件和“校园位置示意”的说明。

地点目录在桌面端默认可见，在移动端可以通过“地点目录”按钮展开或收起。目录底部标明“本部校园 · 苏州 · 人民路”，帮助用户确认当前地图范围。

## 地图图形与航拍参考

地图底色为纯白色，明暗主题下均保持白色底图与一致的建筑、地块色彩，目录和详情等界面跟随站点主题。建筑和地块以可编辑 SVG 绘制，按维护者提供的航拍影像辨认屋顶轮廓、内院、铺地、植被、水面及场地材质；原始影像上南下北，参考时校正原片和局部裁切图的朝向，地图统一北向上。

建筑使用俯视轮廓，逐栋表现屋面分坡、瓦纹、檐口、女儿墙、采光顶和可辨认的设备区：包括紫阳楼的灰瓦与端部楼梯、红楼的红瓦、伟长楼的双屋面与斜向玻璃连廊、实验楼的天井、科学楼的 U 形庭院与木平台、图书馆的玻璃顶、来秀坊的多边形屋面、体育馆的蓝色金属屋面与西侧白色雨棚。古建筑表现重檐、屋脊、廊庑和入口台阶。

楼间地块显示草坪、成排行道树、混合林冠、林间步道、石铺庭院和池岸。水景保留春雨池的水中亭、碧霞池岸线、文庙内的水院，以及泮池东西两片水面和中间南北向石桥；运动区绘制六片蓝色篮球场、独立绿色球场、赭红跑道及条纹草坪。树冠按影像中的覆盖范围和色彩分组绘制，枝叶与材质纹理是可复现的矢量表达，不代表逐株测量。页面标明“航拍参考绘制 · 校园位置示意”。地图保留原有导览坐标和地点关系，非正射测绘成果，不用于测量距离。

图形由 `python3 tools/build-campus-art.py` 生成到 `apps/web/src/maps/campus.svg`，建筑、地块和纹理均为 SVG 图元，不内嵌照片，也不依赖外部图片或图像生成服务。修改轮廓时更新生成脚本；地点位置与名称仍由 `apps/web/src/maps/places.ts` 管理。地图、目录缩略图和详情共用同一套矢量图形。

道路分区绘制沥青、花岗岩大板、错缝石铺、砖铺、卵石及木平台，交汇处使用连续面轮廓。植被按明确的树冠中心、类型与冠幅组织；林地、树木、建筑分层，屋顶遮罩避免树冠盖住建筑。所有地点文字与环境文字置于建筑之上，搜索、分类和选择同步更新文字状态。

Web 构建为 SVG 生成带内容哈希的资源地址，防止新版代码混用旧缓存图形；加载时校验图形版本、必要图层和所有地点符号，不兼容资源进入可重试的错误状态。

iOS 使用 `node --import tsx apps/ios/scripts/sync-resources.mjs --map-only` 同步地点数据，并从同一 SVG 导出原生视图使用的 2 倍分辨率底图。明暗主题下导出的地图色彩一致，原生地图画布也保持白色。

## 地点分类

目录提供“全部、教学、人文、园林、生活、运动”分类。教学对应教学和学习空间，人文对应校史与文化地标，园林对应校园景观，生活对应日常设施，运动对应运动场地。分类按钮显示选中状态，并更新地点数量和地图标记；切换分类保留当前缩放和位置。

## 搜索地点

搜索框的提示语是“寻找校园里的一个地方”。用户输入地点名称、别名、简介中的词、所在区域或分类名称时，列表和地图同步过滤，并实时显示结果数量。搜索会自动展开移动端目录，清空按钮只在有输入时出现。

搜索支持旧称或别名。例如用户输入某个历史名称，结果可以显示现在使用的正式名称；结果行同时展示地点摘要，帮助用户确认是不是要找的地方。按 Enter 时，如果有结果，直接打开第一条地点详情。

没有匹配结果时，目录显示“没有找到这个地点”，建议换名称或分类，并提供“查看全部地点”按钮。恢复全部地点会清除搜索和分类条件。

## 选择地点

用户可以点击地图上的地点、目录中的地点行或地图标记来选择地点。被选中的地点在地图上保持高亮，地图将视野移动到足以看清地点的位置；选择靠近地图边缘的地点时，视野避免把地点推到空白区域。

地点目录行显示缩略插画、正式名称、简短摘要和进入详情的箭头。选择目录行后，在移动端目录自动收起，让用户看到地图和介绍；桌面端保留目录以便继续选择其他地点。地图选择不会改变插画的比例、绘制顺序或其他建筑的可见性。

## 地点详情

详情面板显示地点的分类、正式名称、别名（如有）、插画和分段介绍。介绍可以包含地点用途、所在区域、校园历史、名称来历和与学生日常的关系。地图为校园位置示意，地点介绍不提供实时开放状态或路线规划。存在公开资料时，面板底部提供带来源名称的外部链接，在新页面打开。

打开详情后，焦点移动到地点名称，介绍区域从顶部开始阅读。介绍内容较长时，只在详情内容区域内部滚动，地图和关闭按钮保持可用。点击关闭按钮或按 Esc 关闭详情，并将焦点返回到打开它的地图标记或目录行；如果原控件已经不存在，则返回地图区域。

用户在详情打开期间切换分类或搜索，如果地点仍匹配，详情继续显示并更新高亮；如果不再匹配，详情自动关闭。按 Home 或点击“回到校园全景”也会关闭详情，并把地图恢复到完整校园视野。

## 地图操作

用户可以用鼠标或触控拖动地图。滚轮、双指捏合和带 Ctrl 或 Command 的滚轮用于缩放；地图控件提供放大、缩小和回到全景三个按钮。地图区域获得键盘焦点后，方向键或 W/A/S/D 平移，`+` 或 `=` 放大，`-` 缩小，Home 回到全景。

地图始终提供“上方为北”的罗盘。用户缩放或移动时，地图位置和比例平滑更新，已选地点仍保持在可见范围。移动端在目录展开时触碰地图区域会收起目录，避免目录遮挡操作。

## 加载、重试与离开

地图准备期间显示“正在展开校园…”，地图准备完成后状态提示消失。地图资源加载失败时，地图区域显示“校园导览暂时无法加载”和“重新加载”按钮；点击重试只重新加载地图，不影响外层导航和其他页面。

用户离开地图后再返回，页面重新建立地图视图并回到全景初始状态。地图页面使用独立的整屏布局，但仍保留公共页头、品牌入口、移动导航、主题切换和登录状态。地图外部资料链接离开平台后，返回时仍应能回到原地图页面。
