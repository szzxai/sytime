# 账号与个人空间

## 账号角色与可见范围

访客无需账号即可阅读公开的地图、食谱、菜品、店铺和公告。普通用户可以管理自己的账号、私密收藏夹和工单；完成学生认证后成为学生，可以参与平台内容共建。管理员负责社区管理，运营者拥有更高的账号和运营权限。页面只展示当前账号有权执行的入口，不能通过直接打开链接越过权限限制。

用户主页和公开内容只显示已经生效的资料。待审核的昵称、头像、展示 ID 和签名不会提前出现在其他人的页面；申请结果和拒绝理由会在申请列表与消息箱中同时保留。

## 注册

注册表单要求填写用户名、昵称、密码和确认密码。用户名由 3 至 32 位英文字母、数字、下划线或连字符组成，必须以英文字母开头，注册后不能修改；系统按不区分大小写的方式判断是否重复。昵称最多 20 个字，密码必须至少 8 个字符，包含大写字母、小写字母和数字，首尾不能有空白。

两次密码不一致、用户名格式错误、用户名已被使用或密码不符合要求时，表单保留用户输入并在当前页面说明原因。注册成功后自动登录并返回注册前想访问的页面；若没有来源页面则进入默认入口。新注册账号是普通用户，昵称申请会进入审核，但账号可以立即使用。

## 登录、退出与会话

登录使用用户名和密码。用户名输入不区分大小写，密码错误和不存在的用户名显示相同的失败提示；短时间内反复尝试会暂时限制继续尝试。登录成功后站点记住当前设备的会话；导航入口见[首页与公共体验](home.md)。

退出登录只结束当前设备会话。用户在设置中修改密码、解绑学生身份、被封禁或角色发生变化时，所有设备上的会话都会失效，页面要求用新状态重新登录。会话过期时，当前页面保留可阅读内容，执行需要身份的操作会提示重新登录，并可回到原来的页面。

登录页面遇到已封禁账号时显示封禁原因、封禁说明图片和最近一次申诉状态。若管理员允许在线申诉，页面同时提供申诉表单；不允许申诉时说明需要联系运营者，不能提交空白或绕过限制的申诉。

## 密码与账号安全

设置的“账号安全”区域要求输入旧密码、新密码和确认新密码。旧密码不正确、新密码不符合规则或两次输入不一致时不保存。修改成功后立即结束全部设备会话、清除当前登录状态并通知用户重新登录；密码修改不会改变昵称、收藏、申请记录或其他个人资料。

用户可以选择主动撤销所有设备会话，操作前需要再次输入当前密码。密码验证失败、账号不存在或请求过于频繁时，页面显示原因且不改变会话状态。安全操作完成后不能继续使用旧页面中的需要登录操作。

## 学生身份

未认证用户从账号菜单或个人资料进入“学生身份”。申请需要填写学号或新生号、班级、真实姓名和可选补充信息。学号只能绑定一个账号，待审核申请不会提前占用学号；同一账号在已有绑定时不能重复申请，十分钟内不能重复提交。

提交后页面显示“待审核”，并在个人申请列表中显示申请时间、状态和处理说明。审核通过后账号获得学生权限，学生专属的投稿入口随即开放；同一学号的其他待审申请会自动显示为未通过。审核未通过时保留原因，用户可以根据说明重新提交。

已绑定账号可以看到学号、班级和真实姓名。解绑必须输入当前密码并确认。解绑会释放学号、把账号恢复为普通用户、撤回该账号待审核的学生专属内容、将公开收藏夹改为私密，并让所有设备退出登录；页面明确说明这些影响后才允许提交。

## 封禁申诉

被封禁用户在登录失败页面输入用户名和密码后才能查看申诉入口。申诉理由必填，最多 500 字，可附一张图片；错误密码、账号不允许申诉、图片格式或大小不合要求时不会创建申请。十分钟内重复申诉会显示剩余等待时间。

申诉提交后显示待审核状态，用户可以看到上一条申诉是待审核、已通过、未通过或已撤回。通过后账号恢复登录资格；拒绝后保留处理说明。申诉期间不能通过重复登录或注册新会话绕过封禁。

## 个人主页

个人中心和设置在窄屏幕上使用分区导航。自己的个人中心分为主页、收藏、头衔和申请管理；用户可以在主页查看用户名、展示 ID、昵称、签名、头像、权限标签和当前佩戴头衔。用户名是登录标识，展示 ID 是公开标识，两者分开显示。

查看他人主页时只读显示对方已公开的资料、已佩戴头衔和公开收藏夹。其他人的主页没有编辑资料、佩戴头衔或管理申请的入口；访问自己的用户主页链接会回到个人中心。无效用户编号显示“用户不存在”，不泄露账号是否曾经存在的更多信息。

## 公开资料修改

用户可以直接编辑昵称和签名，按 Enter 或离开编辑区域后出现保存确认；按 Esc 或选择“不保存”恢复原内容。昵称不能为空且最多 20 个字，签名最多 200 个字；展示 ID 需要 3 至 24 位字母、数字或下划线，且不能与他人重复。头像从本地选择后先在当前设备压缩，再提交审核。

每次资料提交都会出现在“我的申请”，状态为待审核；审核期间公开资料仍使用旧版本。待审申请可以撤回，已通过或未通过的申请只能查看结果。成功发布的资料会在个人主页和评价作者信息中同步更新，图片处理失败或网络失败时不会留下半成品。

## 头衔

头衔页列出已经获得的头衔、颜色、说明和获得方式。用户可以选择一个头衔佩戴，也可以选择不佩戴，保存后在个人主页、评价和允许显示身份的位置更新。自动获得但尚未达成的头衔会显示进度和达成条件，不能被选择或手动领取。

查看他人头衔时只能阅读，不能替对方佩戴或取消。头衔被撤销后从可佩戴列表消失，已经显示的公开资料在下一次刷新时同步更新。

## 网站偏好

“网站设置”允许选择访问首页时默认打开首页、校园地图或菜品与食谱；选择食谱默认显示今日与明日、全部菜品、菜品评价或每周食谱。进入必吃榜时可以保存默认排序和默认店铺类型；这些偏好只影响自己的初始列表，不改变公共排序。

用户可以选择店铺详情的纵向或双栏布局，也可以交给屏幕宽度自动选择；手动布局会记住上次在详情页的切换。收藏设置可以指定进入个人中心时默认打开的收藏夹，并设置之后新建收藏夹默认公开或私密；已有收藏夹不受该开关影响。公开收藏的权限与具体规则见[校外就餐](eater.md)。

用户还可以选择是否在评价等位置显示自己的权限等级标签。普通用户没有可隐藏的更高等级时，页面会解释该设置不产生额外效果。保存失败会保留原设置并提示，重新加载不会把未保存的草稿当成已生效配置。

## 申请记录

个人中心的“我的申请”按时间分页显示学生认证、资料变更、封禁申诉以及用户贡献相关申请。每项显示申请类型、编号、提交时间、摘要、当前状态和处理说明；待审核项提供撤回入口，已经处理的项不显示撤回按钮。打开消息中的申请链接会定位并高亮对应记录，返回全部申请不会丢失当前分页。

申请列表加载失败时提供重试，暂无申请时显示空状态。申请通过后，涉及公开内容的记录提供查看目标的入口；目标被删除时仍保留申请结果和说明。

## 消息箱

登录用户从导航或设置进入消息箱。消息按时间倒序排列，可切换全部、系统类或仅未读；每页显示有限数量，滚动或翻页可继续加载更早消息。未读消息在导航中显示总数，进入消息箱不会自动把全部消息标记为已读。

用户可以逐条标记已读，也可以一次标记全部。消息包含标题、正文、重要标记、产生时间和相关对象入口；审核结果、认证结果、账号变更、工单回复和系统公告都在这里汇总。相关对象已经不存在时，消息仍可阅读，但跳转会显示目标不可用的原因。加载失败或网络断开时保留已有消息并提供重试。

## 工单

设置中的“工单”要求登录后使用。新工单填写标题和内容，并选择“管理员及以上”或“仅运营者”的可见范围；标题最多 100 个字，内容最多 2000 个字。每个账号短时间内最多提交有限数量的工单，超出后显示稍后再试。

提交成功后工单显示待处理状态、编号、可见范围和提交时间。用户只能查看自己提交的工单和工作人员回复，不能修改或撤回已经提交的内容。工作人员回复后状态变为已批复，回复人、时间和正文显示在原工单下，并产生一条可跳回设置页的消息。仅运营者可见的工单不会出现在管理员的处理列表中。
