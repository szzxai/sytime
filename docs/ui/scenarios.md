## 1. 数据与内容

### 1.1 超长无空格串（英文/数字/URL）
- 触发：帖子标题/内容、店铺名、昵称出现 `aaaaaaaa…` 或 200 字符的 URL。
- 处理：所有用户内容容器一律 `overflow-wrap: anywhere`（`.prose`、`.card__title`、`.post__excerpt`、`.msg__text` 已内置）；列表标题用 `u-truncate` 或 `-webkit-line-clamp`（`u-clamp-2/3`）截断；表格单元格必须设 `table-layout` 由外层 `.table-wrap` 横向滚动兜底。**禁止** `word-break: break-all`（会把正常中文断得难看）。

### 1.2 超长中文标题
- 处理：帖子标题在卡片里不限长（换行）；详情页 h1 不限长；`<title>` 不截断；公告列表项两行截断（`.master-item__title`）。菜单/下拉里的长名（用户菜单头、批复标题）单行省略。

### 1.3 空字符串字段
- 昵称为空 → 显示用户名；用户名为空 → 「已注销用户」；签名为空 → 占位「介绍一下自己…」；地址补充描述为空 → 不渲染该行（不留空行）。
- 处理：渲染前用 `v = v || 默认值`；**禁止**渲染 `null`/`undefined`/`"null"` 字样。

### 1.4 数字为 null / 非法
- 评分为空 → 不显示星星（`UI.stars(null)` 返回空）；计数为空 → 显示 0；距离/分钟非法 → 不渲染该 `stat` 块（不显示「NaN 米」）。

### 1.5 图片相关
- 加载失败 → ui.js 自动 `is-broken` 占位（见 components.md「Thumb 缩略图」）；地址为空 → 不渲染 `<img>`，渲染分类色占位块（`dish__placeholder`）。
- 图是动图/GIF 被后端拒绝 → 上传前预校验已拦；若接口仍返回错误 → `UI.errorText` 中文提示。
- 图片很大（5000px 宽）→ 容器 `aspect-ratio` + `object-fit: cover` 已兜住。
- 图片被删（404）→ 同加载失败占位；不提供重试单独按钮（刷新列表即可）。

### 1.6 大数据量
- 列表 >20 条 → 客户端「加载更多」每次 20；>500 条 → 照常分批渲染（DOM 最多约 500 节点时性能仍可接受；更多时先到先停，文末显示「已显示全部」）。
- 回复 1000 条 → 详情页全部渲染（分批 20，底部「加载更多」）；楼层号 `data-floor` 由渲染序号生成。
- 骨架屏数量固定 3，不随数据量变。

### 1.7 重复数据
- 同名菜品出现在多个店铺 → 各自独立显示，名字后不带后缀（如需区分见 shops.md 数据契约）。
- 用户连续发布两条相同内容 → 原样显示两条；**前端不做去重拦截**（后端去重规则见 F 节）。
- 邀请码重复（409）→ 内联错误「该邀请码已存在」（copy.md 5.4）。

### 1.8 特殊字符与安全
- 内容含 `<script>`/HTML → 一律 `UI.esc()`，纯文本呈现（不解析富文本）。
- 用户名出现在 HTML 属性（title、data-name）→ `UI.esc()`。
- 图片地址不可信（用户控制）→ `UI.safeUrl()`，非法返回空则走占位。
- 内容含 `\n` → `.prose` / `white-space: pre-wrap` 原样换行。

### 1.9 排序与稳定性
- A–Z 分组：按后端 `initial` 字段（A→Z，`#` 最后），组内按名称拼音序（`Intl.Collator('zh-Hans-CN-u-co-pinyin')`）。缺 `initial` → 不分组、隐藏索引条（见 dishes.md）。
- 列表接口返回顺序不稳定时 → 前端不自行二次排序（保持后端权威），仅菜品目录例外。

### 1.10 时间边界
- `created_at` 缺失/为 0 → 不渲染时间行。
- 未来时间（服务器时差）→ 按相对时间正常显示（不为负数做特殊处理，`diff` 已钳 0）。

## 2. 权限与账号

### 2.1 未登录访问需登录页面（profile/inbox/admin 等）
- 页面脚本开头：`if (!UI.session.token()) { UI.goLogin(); }`（自动带 `?next=`）；登录成功回原页（`UI.nextUrl`）。**禁止**渲染半页面再跳转：检查放在 `<main>` 内容渲染之前。

### 2.2 token 过期（操作中 401）
- `UI.api` 自动：清会话 → toast「登录已过期，请重新登录」→ 0.9s 后带 next 跳登录页。页面脚本**无需**再写 401 分支。
- 批量请求并发 401 → toast 去重（1.2s 窗口内只出现一次）。

### 2.3 权限不足但页面可看（如普通用户在后台）
- admin.html：无任何管理权限 → 整页 `empty--lock`「暂无权限访问管理后台」+「返回首页」（现有逻辑保留，样式换成新组件）。
- 有部分权限 → 侧栏只显示有权的面板（现有 `PANEL_PERMS` 逻辑保留），默认激活第一个可用面板。

### 2.4 被封禁用户
- 登录时 → login.md 的封禁流程（alert--danger + 申诉区/线下联系）。
- 已登录期间被封 → 下一次任何 API 403 时：toast「账号已被封禁」+ 0.9s 后去登录页（登录页会显示封禁详情）。〔待产品确认：是否即时踢出；当前方案够用〕

### 2.5 权限被管理员收回
- 侧栏/按钮的显隐以 `UI.session.user()` 缓存为准；被收回后下次 `UI.shell.refreshAuth()` 或重新登录生效。操作返回 403 → toast「你没有权限执行此操作」并刷新列表（消失的入口随刷新隐藏）。

### 2.6 首个用户是 developer
- 无 UI 差异；注册页不提示此规则（避免剧透）。

### 2.7 退出登录时的未保存内容
- 发布框有内容时退出 → 与其它离开路径一致：`UI.guardUnsaved` 已覆盖 beforeunload；菜单点击不拦截（用户明确点击）。〔可接受〕

### 2.8 多标签页登录状态冲突
- 用户在 A 标签页退出，B 标签页仍在 → B 页下一次 API 401 自动走 2.2 流程。**P2 增强**（不强制）：监听 `storage` 事件，`token` 被清时即时刷新页头。
- 双开页同时登录不同账号 → 后登录者覆盖 localStorage，先登录页下次刷新跟随（接受）。

### 2.9 学生认证审核中
- 认证页再次进入：已达 student → 成功态；pending 且 P2 方案实现（localStorage 记忆）→ 显示「审核中」空态（icon: clock，文案「你的学生认证正在审核中，通过后会以消息通知你」）。P0：显示表单（与现状一致）。

### 2.10 邀请码直通成功
- 接口返回 `approved` → toast「认证成功」→ 0.8s 后显示成功态（`already` 块）并 `UI.session.patch({role:'student'})` 刷新页头。

## 3. 网络与时序

### 3.1 慢网（>8s）
- 骨架屏下方追加一行 `u-muted u-fs-sm`「网络较慢，仍在加载…」（页面脚本在发起请求 8s 后插入，收到响应即移除；`UI.config.slowMs`）。

### 3.2 断网
- ui.js 自动显示 `.offline-bar`；此时发起的请求返回 status 0 → 走加载失败/错误 toast。恢复在线 → 移除黄条 + toast「网络已恢复」；列表不自动刷新（用户手动）。

### 3.3 请求竞态（快速切换筛选/搜索）
- 每个列表容器挂 `AbortController`：新请求发出前 abort 旧的（`UI.api(path, {signal})`）；渲染前校验 `aborted` 不落盘。搜索输入防抖 250ms、IME 组合期间不发。

### 3.4 重复提交
- 按钮 busy 期间不可点；网络慢时用户狂点 → 只发一次。提交成功后表单 reset。

### 3.5 接口 500 / 网关错误
- `UI.errorText` → 「服务器开小差了，请稍后再试」；加载区走 `UI.html.loadError`（带重试）。

### 3.6 服务器返回非 JSON（如 HTML 错误页）
- `UI.api` 已 catch 解析失败 → `{error:'network'}` 处理；界面显示网络失败文案。不显示原始 HTML。

### 3.7 时钟偏差
- 本地时间不准影响相对时间 → 接受（显示偏差可容忍）；**禁止**在前端做时间校准。

### 3.8 页面隐藏时
- 轮询暂停（`document.hidden` 检查已内置）；回前台立即拉一次未读数。

## 4. 输入与校验

### 4.1 输入法（IME）组合
- 搜索、计数、即时校验必须在 `compositionstart…compositionend` 期间暂停，compositionend 后恢复（搜索已规定；计数用 input 事件天然兼容）。

### 4.2 表情符号输入（昵称/店名等）
- 接受原样存储与显示（`UI.esc` 后正常）；**禁止**前端过滤 emoji 字符。〔待产品确认：是否限制；当前不限〕

### 4.3 前后空格
- 所有文本输入提交前 `.trim()`；密码**不** trim。

### 4.4 全半角
- 数字输入（距离/步行时间）用 `inputmode=numeric` + type=number；用户输入全角数字 → type=number 拦截大部分；仍混入时 parseInt 失败 → 内联提示「请输入数字」。

### 4.5 输入超上限
- `data-counter` 显示 `n / max`，超限红字（`is-over`）；提交时超限 → 字段错误「内容不能超过 N 字」。**不自动截断**用户输入。

### 4.6 必填校验顺序
- 从上到下首个错误字段聚焦（`UI.form.focusFirstInvalid`）。

### 4.7 地址格式校验
- 地址须包含道路/巷坊名和 `数字+号`：匹配 `路|街|巷|道|弄|坊|河沿` 且 `\\d+号`；例如「三元路 12 号」「滚绣坊 51 号」。不满足时显示地址格式错误。

### 4.8 文件拖拽上传
- `.upload` 支持 dragover/drop（`UI.upload` 已实现）；拖入非图片/超大文件 → 同选择文件的错误提示。

### 4.9 粘贴图片
- **P2，默认不做**。不做任何处理（粘贴到 textarea 只出文本）。

### 4.10 表单 reset 后的计数残留
- reset 后手动触发一次 `input` 事件或调用 `UI.form.counter(el)` 更新（页面脚本负责）。

## 5. 布局与设备

### 5.1 极窄屏（320px）
- 所有容器自带 `min-width:0` 与内边距令牌；320px 不出现横向滚动是 P0 验收项（360 是基准，320 尽力）。
- 网格列最小 `--grid-min` 用 `min(100%, …)` 已防溢出。

### 5.2 横屏手机（如 740×360）
- 高度 <500px 时：`.auth` 卡居中改为顶部对齐（CSS 未强制，可接受）；地图页浮层不变（楼层条右侧竖排不变）；对话最大高 90dvh 已适配。

### 5.3 平板（768–899）
- 页头导航显示（≥768）；个人中心/后台侧栏仍为吸顶横条（<900）；店铺双栏 <900 强制样式一。

### 5.4 桌面超宽（>1600）
- 容器封顶（--w-*），两侧留白自然变大；**禁止**拉伸容器。

### 5.5 浏览器缩放 200%
- 全部 rem 布局，正常缩放；验收时用 200% 走一遍主要页面（无遮挡、无横向滚动）。

### 5.6 刘海屏 / 安全区
- 吸顶元素加 `--safe-top`（页头由 ui.js 处理；自写吸顶须加）；底部面板/抽屉/吸底操作栏加 `--safe-bottom`（CSS 已内置）。

### 5.7 打印
- `@media print` 已内置（藏页头页脚按钮等，链接显示 URL）；公告详情、帖子详情可打印。新页面无需额外处理。

### 5.8 老浏览器（不支持 <dialog / CSS 变量）
- 特性检测 + 静态提示条（见 system-pages.md「浏览器过旧」）；不写 polyfill。

### 5.9 触屏没有悬停
- 所有关键操作不依赖 hover（hover 只是增强）；卡片点击有 `:active` 反馈（`translateY(1px)`）。

### 5.10 系统深色偏好但站内浅色
- 按决策表 D20：不自动跟随；用户觉得刺眼属预期（P2 上线「外观」后自选）。

## 6. 交互细节

### 6.1 双击/双触
- 提交类按钮 busy 防重；点赞类幂等（接口已幂等）；卡片双击不产生两次跳转（click 只触发一次 location）。

### 6.2 右键
- **禁止**自定义右键菜单（旧论坛的 contextmenu 删除菜单废弃）；删除入口一律 ⋯ 菜单。

### 6.3 拖拽选择文本
- 卡片整卡可点（伪元素）会阻挡文本选择——接受：内容选择需求用详情页；**列表卡禁止**嵌套可选交互区之外再加大段可选文本按钮。

### 6.4 锚点定位被吸顶遮挡
- 锚目标自带 `scroll-margin-top`（CSS 已设）；新增锚点区块必须设置同样值（`calc(var(--header-h) + var(--sp-4))`）。

### 6.5 平滑滚动失败（旧浏览器/系统设置）
- `scrollIntoView` 传 `behavior: REDUCED ? 'auto' : 'smooth'`；不支持时回落即时跳转（可接受）。

### 6.6 焦点丢失（点击后 focus 在 body）
- 对话框/抽屉关闭后焦点回触发元素（原生 dialog 自动）；菜单关闭 Esc 后回触发器（ui.js 已做）。自写交互须遵守。

### 6.7 长按（移动端）
- 长按出系统菜单为浏览器默认，不拦截。

### 6.8 滚动绑定
- 字母索引点击 → 平滑滚动到组；滚轮在对话框内不透传（`overscroll-behavior: contain` 已设）。

### 6.9 键盘焦点顺序异常
- DOM 顺序即视觉顺序（先标题后操作）；弹层用原生 dialog 保证顺序。验收时 Tab 一圈核对。

### 6.10 页面刷新丢滚动位置
- 接受（无恢复逻辑）；锚点 URL（#reply-123）加载时定位到目标并高亮（post.md）。

## 7. 管理后台

### 7.1 待办数与实际列表不一致（竞态）
- 处理完最后一条 → 列表区显示空态 + 侧栏计数在下一次 `refreshDots` 归零；中间态短暂不一致可接受。

### 7.2 批量操作
- **不做**多选批量（当前需求无）；每条独立操作。

### 7.3 两个管理员同时操作同一申请
- 后到的操作返回「该申请不存在或已处理」（application not found）→ 刷新列表 + toast（copy.md 5.4）。

### 7.4 封禁理由含敏感词/超长
- 输入不限制长度（后端 TEXT）；显示时 `.queue-item__fields` 自动换行。

### 7.5 上传中关闭浏览器
- 未完成的操作自然失败；无恢复。可接受。

### 7.6 日期倒填（start > end）
- 提交前校验：`if (start > end)` → 字段错误「第一天不能晚于最后一天」（在 admin.md 周菜谱面板）。

### 7.7 表格内下拉被裁剪
- `.table-wrap` 横向滚动兜底；不在表格内用复杂弹层。

### 7.8 后台数据自动刷新
- 不自动刷新列表（避免操作被打断）；侧栏计数每 60s 与消息铃同批刷新（P2）。

## 8. 新功能边界

### 8.1 功能开关未打开时访问新页面
- features.shops=false 但直接访问 shops.html → 页面顶部 `empty--lock`「该功能尚未开放」+「返回首页」（页面脚本检查 `UI.config.features.shops`）。其余新页面同理。

### 8.2 店铺被删除后详情页
- 404 → `empty`「店铺不存在或已被删除」+「返回必吃榜」。

### 8.3 菜品无图（学生未传）
- 菜品卡显示分类色占位（按店铺类型 hue 或按 id `UI.hueFor`）；详情同。

### 8.4 消息目标已被删除
- 消息条目仍显示，点击 → 目标页 404 态「帖子不存在或已被删除」（消息不标记失败，正常标已读）。

### 8.5 头衔被撤销时正在佩戴
- 下一次 `UI.shell.refreshAuth()` / 列表渲染时徽章自然消失；个人中心「我的头衔」不再出现该选择卡；系统消息告知（titles.md）。

### 8.6 消息偏好全部关闭
- 互动类不再产生新消息；系统消息中的「重要」类仍会出现在消息箱（不可关闭）。

### 8.7 未读数接口尚未上线（P1 期间）
- `features.inbox=false`：页头无铃铛；inbox.html 走 8.1 处理。

### 8.8 搜索命中拼音缩写
- 仅当后端提供拼音字段时支持（dishes.md 数据契约）；缺字段时只匹配名称本身，不做前端拼音转换。

### 8.9 评价分数 0 分
- 合法值（后端 0–5）；显示 0 颗实心星 + 「0 分」；不显示「无评分」。

### 8.10 店铺距离为 0（校内店铺）
- 显示「0 米 · 校内」；步行时间仍显示。〔待产品确认：校内店铺的呈现；当前方案〕
