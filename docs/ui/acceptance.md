## 复验

在项目根目录运行：

```powershell
npm.cmd ci
npm.cmd test
```

Windows 默认使用已安装的 Microsoft Edge；其他平台先执行 `npx playwright install chromium`，再运行 `npm test`。测试脚本为 [tests/ui-smoke.mjs](../../tests/ui-smoke.mjs)，结果和截图写入被 Git 忽略的 `output/playwright/`。

参考组件的 101 项结果来自实施阶段的独立设计工具；仓库内可复现的自动化入口是上述浏览器回归。`docs/ui/assets/` 保留设计参考，`public/` 是实际运行实现，两者不要求逐字相同。

运行 `npm.cmd start` 后访问 `http://localhost:3000/` 可人工检查；样张位于 [assets/specimen.html](./assets/specimen.html)。明暗主题都经过扫描，主题切换入口属于手册 P2 功能，当前未开启。
