# 全部菜品 · Issue #5

## 当前视觉与布局 · 2026-10-24

菜品目录纳入菜谱工作区，搜索在左栏，右侧按字母分组显示细边框菜名网格（桌面三列，平板/手机两列）。目录保留原始名称，点击后进入真实评价驱动的详情，不虚构图片、介绍、价格或评分。全站品牌字标为「拾光酥糕」，详细公共尺寸见 [UI.md](../../../UI.md)。本轮验证结果见 [验收记录](../acceptance.md) 和根目录 [MAP.md](../../../MAP.md)。

> 入口：`recipe.html?view=all`。目录基于用户确认的 [计划](../../issue-5-plan.md)，2026-10-24 按后续要求增加详情与已有菜品选评；计划文件保留历史范围。

## 页面结构

「菜品与食谱」页面含全部菜品、菜品评价、每周食谱三个页签。全部菜品显示搜索框、数量与更新时间、A–Z 分组列表及右侧索引。名称可换行，索引只出现有结果的分组。目录为独立菜品实体，评价记录继续在「菜品评价」页签显示。

目录行仍只显示原始名称，使用 `<li>` 内的原生 `<a class="dish-row__name card__link">` 跳转至 `dish.html?id=...`，整行可点击并保留列表语义，支持回车及浏览器原生新标签页。详情展示该菜品的平均评分、评价数和分页图文评论；规范见 [dish-detail.md](./dish-detail.md)。店铺关联不在本次范围。

## 菜名字体 · 2026-10-24

- `.workspace--recipe .dish-directory .dish-row__name` 使用 `--font-sans-system`：优先系统已有的苹方、HarmonyOS Sans SC、完整 Noto Sans SC、微软雅黑等中文无衬线字体，不混入本地精简的 `NotoSansSC` 字形子集。
- 菜名统一为 `--fw-regular`（400），桌面 14px、手机 13px；长名称按原有规则换行，搜索命中片段继承菜名的字体、字号与字重。
- 字体修复本身仅涉及菜名排版，不新增外部字体请求；后续详情功能将点击改为原生链接，A–Z 分组标题、计数、索引及搜索保持不变。
- 浏览器回归覆盖 1,243 个历史菜名在 360/1280px、明暗主题下的字体、字重和字号，并检查搜索高亮继承。执行结果见 [验收记录](../acceptance.md)。

## 数据与排序

`GET /api/dishes`：

```json
{"dishes":[{"id":12,"name":"重庆小面","initial":"C","pinyin":"chongqingxiaomian","pinyin_initials":"cqxm","sort_key":"chong qing xiao mian"}],"meta":{"total":1,"source_count":1,"records_count":1,"updated_at":1790812800000,"last_sync_success_at":null}}
```

排序在 Node 中统一完成：A–Z、#、完整拼音、名称归一键、稳定 ID。前端不重新排序，不使用浏览器 Collator 决定目录位置。名称归一采用 NFC、去两端空白、合并空白、大小写归一；显示保留首次写法，不转换繁简体或拆分套餐。

历史种子和新识别都使用同一 `pinyin-pro` 路径及词组覆盖。目录只显示至少存在一条成功供应记录的菜品；来源更新不会重排已有实体 ID。

## 搜索与访问

- 菜名子串、完整拼音和拼音首字母均可搜索，拉丁输入不区分大小写，可含空格。
- 输入防抖 250ms，中文 composition 期间暂停；结束后更新。
- 仅对名称中的原文命中段添加 `mark`，其他文本转义，拼音命中无需高亮汉字。
- 清除恢复全量并聚焦输入框。结果仍按原有 A–Z 顺序分组。
- URL 保存 `view`、`q`，刷新可恢复，明确 URL 优先于账号默认视图。无 URL 时沿用账号 all/reviews/weekly 设置，all 对应目录。
- 搜索结果数用状态文本和屏幕阅读器播报；索引为真实锚点，当前分组用 `aria-current` 标识。
- 目录链接传递稳定菜品 ID，不传用户输入的显示名称；详情按 ID 关联评价，旧非每周评价仅按同一归一名称规则补关联，无法匹配的旧内容仍保留在原「菜品评价」栏。
- 详情或菜谱的写评价对话框中，选菜候选首批 50 条，「显示更多」每次追加最多 50 条，更换关键词重置；这是选菜浮层的显示批次，不限制本页目录数量，也不改变评价列表的二十条分页。

## 状态与适配

首次请求为行骨架，失败为中文提示及重试；空目录显示等待同步，搜索无结果提示尝试菜名、拼音或首字母。目录不显示「写评价」按钮；切换评价页签后恢复。

360px 与 1280px、明暗主题使用现有令牌与组件。右侧索引占位不覆盖名称，长名称换行，不发生页面横向滚动。URL 输入作为数据处理，不插入可执行 HTML。
