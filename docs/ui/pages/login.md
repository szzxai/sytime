# 登录 · login.html

更新：2026-10-31。`AuthPages.LoginPage` 使用共享账号卡片和密码显隐。

登录仅校验用户名、密码和账号状态，**不显示或检查密码强度**，可登录既有弱密码账号。必填校验与显隐保留，不加新密码规则。正确凭据建立 HttpOnly、SameSite=Strict 会话；HTTPS/生产同时 Secure。本地存储仅会话标记和公开资料，不保存新 JWT。

成功后按安全的站内 next 地址返回。错误凭据使用统一提示；限流有稍后重试提示。封禁显示原因，只有允许申诉时展示理由和可选图片。申诉提交仍在后端复核凭据、封禁状态、开关、图片与十分钟间隔；改 DOM 不能绕过。

注册入口保留 next。退出登录撤销当前会话，改密、角色/封禁变化和解绑撤销全部会话。

## 实现与验证

当前实现：React + TanStack Query/Router，Hono + SQLite/Drizzle。权限以数据库当前角色、状态和有效会话为准，隐藏入口不能替代后端校验。验证命令、实测结果与限制见根目录 [MAP.md](../../../MAP.md) 最新记录，以及 [验收记录](../acceptance.md)。
