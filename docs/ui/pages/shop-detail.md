# 店铺详情与推荐 · shop.html / shop-new.html

更新：2026-10-31。保留地图降级、路线信息、手动/自动双栏与收藏。

学生及以上可推荐店铺，校验完整道路门牌、类型、坐标围栏、步行距离/时间和可选安全大众点评链接。提交返回 202 申请，提示等待审核并转个人中心；同名检查在提交和批准时执行。每日最多 10 次推荐。

每人每店一条已发布评价，可提交修改、1–5 星、最多 500 字、人数/总价和可选配图。新评价和修改都待审，通过前仍保留旧版本。图片不提前公开，批准后更新评分及评价列表。删除自己的评价同时撤回其未通过修改，避免随后审核让已删内容复现。

user 和 guest 看不到互动表单，后端也拒绝越权写入。私人申请和审核原因在个人中心查看，决定送消息箱。不存在或非法店铺编号显示空态。

## 实现与验证

当前实现：React + TanStack Query/Router，Hono + SQLite/Drizzle。权限以数据库当前角色、状态和有效会话为准，隐藏入口不能替代后端校验。验证命令、实测结果与限制见根目录 [MAP.md](../../../MAP.md) 最新记录，以及 [验收记录](../acceptance.md)。

## 2026-10-31 图片与评价通知修正

共享图片选择器对超过 2 MiB 的 JPG/PNG 在本机缩小尺寸并逐步调整编码质量，压缩到服务端限额后再上传；预览显示处理后文件大小，处理中有提示且禁止提交，失败显示可重试提示，快速换图使用最后一次选择。服务端保留真实图片解码和大小校验。

评价详情支持 `review` 查询参数与 `#review-<编号>` 定位。后端仅返回当前菜品/店铺下匹配的公开评论，允许单独加载第一页之外的目标；页面不重复显示已在列表中的评论，滚动聚焦并强调目标卡片。未通过或已删除内容由通知跳私人申请原文和原因。
