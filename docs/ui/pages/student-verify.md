# 学生身份 · student_verify.html

更新：2026-10-31。`StudentIdentity` 由 `StudentVerifyPage` 挂载，仅登录用户可访问。

填写学号/新生号、班级、真实姓名和可选补充信息，人工核对。学号经 NFKC 规范化并转大写，仅接受 2–32 位字母、数字、连字符。待审不占用身份，一人可有一份待审认证；十分钟内最多提交一次。

批准使用立即写事务，数据库学号主键及账号唯一键确保一个身份只绑定一个账号。先通过的申请生效，同学号其他待审申请立即自动拒绝并收到原因；后来申请也不能绑定已占用身份。普通账号批准后成为 student，管理角色保留管理身份。

已绑定卡片显示本人学号、姓名与班级。本人输入密码可解绑；管理员可按目标保护规则解绑。释放身份，student 恢复 user，撤回待审认证与评价/推荐，公开收藏转私密，退出所有设备。历史已发布评价保留。解绑后可重新申请。没有邀请码入口或接口。

## 实现与验证

当前实现：React + TanStack Query/Router，Hono + SQLite/Drizzle。权限以数据库当前角色、状态和有效会话为准，隐藏入口不能替代后端校验。验证命令、实测结果与限制见根目录 [MAP.md](../../../MAP.md) 最新记录，以及 [验收记录](../acceptance.md)。
