# 用户主页 · user.html

更新：2026-10-31。通过数字内部 ID 定位用户，头部以用户名与审核后的昵称为主要身份；展示 ID 只在低强调辅助行显示，保留头像及签名。

自己进入自己的主页会转个人中心。他人资料只读，保留公开收藏和头衔、角色显示偏好。user 的角色标签沿用始终显示约定。只有权限足够的管理者看到管理入口，跳到统一后台用户管理；没有旧内嵌授权表单。

## 实现与验证

当前实现：React + TanStack Query/Router，Hono + SQLite/Drizzle。权限以数据库当前角色、状态和有效会话为准，隐藏入口不能替代后端校验。验证命令、实测结果与限制见根目录 [MAP.md](../../../MAP.md) 最新记录，以及 [验收记录](../acceptance.md)。

头像与昵称仅使用已批准版本；辅助 ID 不替代用户名标题，不改变内部数字用户链接。
