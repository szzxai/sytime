# 注册 · register.html

更新：2026-10-31。所有新账号均为 user，首个账号也不自动提权。没有邀请码。

填写登录用户名、昵称、密码及确认密码。用户名 3–32 位，英文字母开头，可含字母/数字/下划线/连字符，服务端转小写并检查唯一。昵称提交审核；通过前使用系统生成的用户昵称。

新密码要求至少 8 字符、大小写英文字母和数字，首尾无空白、UTF-8 最多 72 字节。密码下方逐条列出要求，满足项显示绿色勾选与浅绿背景，提供显隐按钮；不额外要求特殊字符。客户端提示用于反馈，注册与改密均由后端强制执行。确认不一致时不提交。

成功后自动登录并返回站内 next。注册有限流，错误保留输入；运营者由服务器 CLI 独立创建。

## 实现与验证

当前实现：React + TanStack Query/Router，Hono + SQLite/Drizzle。权限以数据库当前角色、状态和有效会话为准，隐藏入口不能替代后端校验。验证命令、实测结果与限制见根目录 [MAP.md](../../../MAP.md) 最新记录，以及 [验收记录](../acceptance.md)。
