# 管理后台 · admin.html

更新：2026-10-31。实现为 `AdminPage.tsx`、`AdminPage.css`、`AdminUsers.tsx` 和共享头衔组件；旧菜单、上传、地图编辑、邀请和个人授权面板全部删除。

## 权限

仅 active admin / operator 可进入。admin 管理 user / student；operator 还可任免和管理 admin。不能管理自己或 operator；学生角色必须有已批准的唯一学生绑定，不能靠角色下拉框绕过认证。所有请求重新鉴权，角色与封禁修改撤销目标全部会话。

## 现代管理工作台

桌面 230px 侧栏、独立顶栏、概览欢迎区和四项指标卡；手机导航横向滚动，指标双列、表格内部滚动。复用站点绿色令牌，支持明暗主题。导航为工作概览、审核中心、用户管理、工单处理、站点内容、头衔管理、操作记录。

概览统计待审、工单、北京时间今日处理量和账号总数。审核按类型、状态筛选，每页 20 项；详情私密展示申请内容、图片和申请人，公开资料无提前覆盖。通过与拒绝都二次确认，拒绝必须说明原因。禁止自审、重复处理、失效身份发布；学生竞争申请在同一事务内自动拒绝并通知。失败保留详情可重试。

用户管理支持搜索、分页、角色、封禁/解封、是否允许申诉、解绑和头衔。工单按 admin / operator 可见范围隔离，不能回复自己工单或重复处理。站点内容包括横幅、公告与系统通知；操作记录分页展示处理人、目标、动作和时间，不记录密码、会话令牌。

## 无障碍

按钮提供稳定名称；私密详情与确认使用原生 dialog，Esc 关闭并恢复焦点。表格滚动区可键盘聚焦，手机不撑宽文档；加载、空态、错误重试和提交禁用状态明确。

## 实现与验证

当前实现：React + TanStack Query/Router，Hono + SQLite/Drizzle。权限以数据库当前角色、状态和有效会话为准，隐藏入口不能替代后端校验。验证命令、实测结果与限制见根目录 [MAP.md](../../../MAP.md) 最新记录，以及 [验收记录](../acceptance.md)。

## 2026-10-31 桌面与审核确认修正

工作台铺满桌面可用宽度，取消 1600px 外框限制和两侧外边框，保留内容卡片与侧栏分隔。通知可通过 `?request=<申请号>#reviews` 直接打开对应审核详情。

详情与确认在同一个原生 dialog 内分步切换，不叠加第二个遮罩。确认按钮明确为“确认通过”或“确认不通过”；通过使用主色，拒绝使用警示色并重述原因。“返回检查”、关闭或 Esc 返回详情并保留填写内容；处理中禁用重复操作，失败留在确认步骤可重试。叉号始终位于标题右侧、垂直居中，详情采用宽对话框。
