# 设置 · settings.html

更新：2026-10-31。保留安全、网站、工单和消息偏好面板。

修改密码需正确旧密码、新密码和一致的确认值。仅新密码显示逐项强度要求，旧密码和确认框不展示强度列表。服务端验证不少于 8 字符且包含大小写字母与数字、首尾无空白、最多 72 UTF-8 字节；成功撤销所有会话并回到登录。

网站设置包括默认进入页、菜谱视图、店铺排序/类型/布局、收藏默认页与角色展示。未设置默认收藏时为“自动选择”。新建收藏默认公开即时保存，但 user 不能创建或切换为公开收藏；升级学生后才可公开。该偏好不批量改写已有收藏。

工单为私密反馈，选择管理员或仅运营者可见；后端同样校验范围，每十分钟最多 5 次。本人可查看提交和回复，后台一次性处理并通知；保留未保存离开提醒。

## 实现与验证

当前实现：React + TanStack Query/Router，Hono + SQLite/Drizzle。权限以数据库当前角色、状态和有效会话为准，隐藏入口不能替代后端校验。验证命令、实测结果与限制见根目录 [MAP.md](../../../MAP.md) 最新记录，以及 [验收记录](../acceptance.md)。
