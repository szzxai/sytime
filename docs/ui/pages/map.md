## 目的与内容

默认展示完整的北向上校园导览，按用户提供的新版位置参考图（2026-10-17）校准相对位置与地块轮廓。包括 31 个地点：伟长门、北门、西紫阳楼、东紫阳楼、伟长楼、三元楼、西红楼、东红楼、西红楼草坪、东红楼草坪、智德之门、实验楼、科学楼、东门、希文楼、春雨池、道山、尊经阁（校史馆）、篮球场、碧霞池、图书馆、苏州文庙、来秀坊、道梦空间、体育馆、操场、采芹园、泮水居、政道楼、府学碑廊、泮池与泮桥。「来秀坊」「泮水居」名称已由用户确认。

导览是位置示意，不是测绘图；建筑插画表达建筑类型，不代表真实立面、楼层数或开放情况。文庙用围合地块、殿堂与庭院结构区分，详情说明通行情况以现场为准。没有虚构路线规划、定位或步行时长。

31 个地点提供用途或文化背景介绍；原有28处保留已确认内容，政道楼原名墨子馆，已按维护者补充改名并注明“文正之道”、对李政道先生的致敬及北京大学中学物理实验教学中心用途；保留旧名搜索别名。当前年级分配、办公、餐饮、住宿和场馆功能采用维护者确认的信息，结合已阅读的学校官网和我苏网原文补充校史、课程与活动背景；详细口径见 [地点资料来源](../../map-sources.md)。正文不复述方位，详情卡不再显示位置行。希文楼归入「生活」，目录副标题显示用途摘要，可搜索「面档」「宿舍」「大食堂」等用途词。

## 视觉与布局

- 页面专用样式 `public/css/map.css`，不修改共享导航和其他页面。系统字体、近白底色、克制的圆角、细边框、半透明浮层和低饱和绿地，整体采用简约的系统应用风格。
- 桌面：左侧 308px 地点目录（窄桌面 280px、大桌面 340px），右侧地图占剩余视口。目录头部、搜索和筛选固定，地点列表独立滚动。
- 700px 及以下：头部简化，搜索和分类在地图上方；「地点目录」展开可滚动目录，搜索与筛选自动展开，选择地点后收起。详情卡在地图下方浮动，右侧为独立缩放按钮，不遮挡操作入口。
- 右上为北向标识，右下为放大、缩小和回到校园全景；不显示视图切换器。下方常驻示意图说明。
- 地图中的建筑、水面、山体、花园和球场均为本地 SVG，目录缩略图及详情复用同一组 SVG symbol；无在线底图、图片或字体服务依赖。
- 按参考图重排建筑：三元楼为纵向长条，科学楼为向西开口的 U 形院落，伟长楼、实验楼、图书馆、来秀坊及南部生活楼展示各自地块轮廓；尊经阁位于道山东南、碧霞池东侧。
- 篮球场采用 132 × 292 的纵向场地：北部两列三排、南部独立一片；操场扩大为 310 × 568，含六条跑道与足球场中线、中圈、禁区和球门。场地轮廓按参考图组织，标线仍是示意。
- 春雨池为矩形，碧霞池为转折岸线；道山展示矩形园地、曲径与植被。补绘道山东侧林地、交叉园路及中央景观，文庙展示围墙、院落、殿堂、廊道与两条蓝色地表细节。新增泮池双水面与中央泮桥、东南及南侧竹林、道路与行道树。粉色地块保留无名轮廓；梦工厂按图绘为西侧周边参考轮廓，不推断归属和通行。
- 标签支持独立水平/垂直偏移与基础字号，小地标使用较小标签；热区不再向南多扩展40个坐标单位，避免选到邻近建筑。篮球场名称移至自身地块底部，不与操场轮廓、热区重叠；点击标签下缘也应打开篮球场。屋面、墙体、草坪、绿篱、水体、园路与球场标线均随明暗主题调整。
- 选中、悬停与键盘焦点光晕统一绘制在所有建筑下方；建筑组不重排、不放大，不改变相邻插画的遮挡顺序。
- 详情标题和关闭按钮固定，正文与来源链接在卡内滚动，避免长介绍撑出地图。桌面最高 460px，手机最高 340px，同时受地图可用高度限制；手机额外为地图保留上方可见区域，避免长文卡片占满避让空间；横屏隐藏详情插画。正文区域可键盘聚焦和滚动，引用链接在新标签页打开。
- 明暗主题均使用独立页面令牌；暗色地图同步改变地面、道路、文本、面板和轮廓颜色。`prefers-reduced-motion` 禁用界面过渡和选点动画。

## 交互

- 搜索按地点名、别名、用途摘要、区域和分类文本匹配；「校史馆」能找到尊经阁，「面档」能找到希文楼。搜索与分类取交集。分类为全部、教学、人文、园林、生活、运动；出入口可通过全部或搜索查找。
- 搜索结果显示数量；不匹配的地图地点淡化、不可点击，也不进入键盘焦点顺序。空结果显示提示与「查看全部地点」。清空搜索只清空关键词；查看全部同时清空分类。
- 点击目录或地图插画，显示名称、分类、分段介绍与可查阅的来源，保持当前缩放级别和建筑绘制顺序。
- 已在可见区域且未被详情遮挡的地标不移动。其余地标按地图留白、详情卡及控制条的实际矩形计算可用区域，选择移动距离最短的避让位置，不强制居中；键盘聚焦离屏地标使用相同逻辑。平移采用 460ms 缓出动画，连续选点或用户手势可中断；减少动态效果模式直接完成平移。
- 关闭或 Escape 收起详情并将焦点还给来源；若手机目录已收起，则返回地图。筛选排除已选地点时关闭详情。
- 鼠标拖动、普通滚轮或触控板双指滚动均平移地图，支持横纵两轴；Shift + 纵向滚轮横向移动。拖动不触发选点。
- 触控板捏合、Ctrl / ⌘ + 滚轮连续缩放，并保持指针下的位置稳定。禁用 Leaflet 原生滚轮缩放，按像素归一化事件并用动画帧合并更新。Safari 使用原生手势事件，手势期间忽略重复的滚轮事件。手机保留双指缩放。
- 地图可自由平移，不使用会在宽屏下回弹的固定边界。回到校园全景关闭详情并重置视野；缩放与平移后保持用户视野，处于全景时窗口尺寸变化重新适配。
- 导览地图聚焦时：方向键 / WASD 平移，`+` / `-` 缩放，Home 回到全景。键盘操作不劫持搜索输入。地点可 Tab 聚焦、Enter / 空格打开；离开当前视野的键盘焦点会自动移入视野。

## 状态与接口

导览读取同源 SVG 与静态地点目录，不依赖地图 API。SVG 加载失败显示「校园导览暂时无法加载」及「重新加载」。加载成功后隐藏状态层。

地图不读取账号默认楼层，也不请求旧地图接口。设置页不再显示、提交或写入本地默认楼层；后端 `default_floor` 字段、旧地图读取与弹窗保存接口保留兼容，但不影响当前页面。静态导览说明由文件维护。
