# 校园地图 · map.html

更新：2026-10-31。31 个静态地点、SVG 校园图、搜索、分类、详情、键盘/触控、缩放与明暗主题保持。

所有人可公开浏览；网站不提供地图编辑入口、编辑权限或写接口。当前地图通过仓库地点数据与 SVG 维护，兼容旧地图读取不是在线编辑功能。账号角色变化不改变公开地图行为。独立地图浏览器回归保留。

## 实现与验证

当前实现：React + TanStack Query/Router，Hono + SQLite/Drizzle。权限以数据库当前角色、状态和有效会话为准，隐藏入口不能替代后端校验。验证命令、实测结果与限制见根目录 [MAP.md](../../../MAP.md) 最新记录，以及 [验收记录](../acceptance.md)。

## 2026-10-31 手机目录关闭

700px 及以下展开地点目录后，指针/触摸按下目录外的地图区域即收起目录；目录内搜索、筛选和滚动不触发关闭。使用捕获阶段处理，保留地图原有地标点击、平移和缩放，不增加遮罩拦截。桌面常驻目录不受此行为影响。
