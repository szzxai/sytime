# 校园地图 · map.html

> 更新：2026-10-17。页面只保留 SVG 校园地图，已移除旧楼层平面、顶部视图切换器和默认楼层设置。页面使用应用壳，保留本站导航，无页脚。

## 目的与内容

默认展示完整的北向上校园导览，按用户提供的卫星图手绘标注整理相对位置。包括 28 个地点：伟长门、北门、西紫阳楼、东紫阳楼、伟长楼、三元楼、西红楼、东红楼、西红楼草坪、东红楼草坪、智德之门、实验楼、科学楼、东门、希文楼、春雨池、道山、尊经阁（校史馆）、篮球场、碧霞池、图书馆、苏州文庙、来秀坊、道梦空间、体育馆、操场、采芹园、泮水居。「来秀坊」「泮水居」名称已由用户确认。

导览是位置示意，不是测绘图；建筑插画表达建筑类型，不代表真实立面、楼层数或开放情况。文庙用独立区域和虚线边界区分，详情说明通行情况以现场为准。没有虚构路线规划、定位或步行时长。

## 视觉与布局

- 页面专用样式 `public/css/map.css`，不修改共享导航和其他页面。系统字体、近白底色、克制的圆角、细边框、半透明浮层和低饱和绿地，整体采用简约的系统应用风格。
- 桌面：左侧 308px 地点目录（窄桌面 280px、大桌面 340px），右侧地图占剩余视口。目录头部、搜索和筛选固定，地点列表独立滚动。
- 700px 及以下：头部简化，搜索和分类在地图上方；「地点目录」展开可滚动目录，搜索与筛选自动展开，选择地点后收起。详情卡在地图下方浮动，右侧为独立缩放按钮，不遮挡操作入口。
- 右上为北向标识，右下为放大、缩小和回到校园全景；不显示视图切换器。下方常驻示意图说明。
- 地图中的建筑、水面、山体、花园和球场均为本地 SVG，目录缩略图及详情复用同一组 SVG symbol；无在线底图、图片或字体服务依赖。
- 篮球场采用 210 × 330 的纵向场地区域，包含三个示意球场，与 290 × 370 的操场形成相称的视觉分量；场地数量和标线均为示意。
- 明暗主题均使用独立页面令牌；暗色地图同步改变地面、道路、文本、面板和轮廓颜色。`prefers-reduced-motion` 禁用界面过渡和选点动画。

## 交互

- 搜索按地点名、别名、区域和分类文本匹配；「校史馆」能找到尊经阁。搜索与分类取交集。分类为全部、教学、人文、园林、生活、运动；出入口可通过全部或搜索查找。
- 搜索结果显示数量；不匹配的地图地点淡化、不可点击，也不进入键盘焦点顺序。空结果显示提示与「查看全部地点」。清空搜索只清空关键词；查看全部同时清空分类。
- 点击目录或地图插画，定位并放大到对应地点，突出选中插画，展示名称、分类、位置和描述。地图中的选中点向上留出详情卡空间。
- 关闭或 Escape 收起详情并将焦点还给来源；若手机目录已收起，则返回地图。筛选排除已选地点时关闭详情。
- 鼠标拖动、普通滚轮或触控板双指滚动均平移地图，支持横纵两轴；Shift + 纵向滚轮横向移动。拖动不触发选点。
- 触控板捏合、Ctrl / ⌘ + 滚轮连续缩放，并保持指针下的位置稳定。禁用 Leaflet 原生滚轮缩放，按像素归一化事件并用动画帧合并更新。Safari 使用原生手势事件，手势期间忽略重复的滚轮事件。手机保留双指缩放。
- 地图可自由平移，不使用会在宽屏下回弹的固定边界。回到校园全景关闭详情并重置视野；缩放与平移后保持用户视野，处于全景时窗口尺寸变化重新适配。
- 导览地图聚焦时：方向键 / WASD 平移，`+` / `-` 缩放，Home 回到全景。键盘操作不劫持搜索输入。地点可 Tab 聚焦、Enter / 空格打开；离开当前视野的键盘焦点会自动移入视野。

## 状态与接口

导览读取同源 SVG 与静态地点目录，不依赖地图 API。SVG 加载失败显示「校园导览暂时无法加载」及「重新加载」。加载成功后隐藏状态层。

地图不读取账号默认楼层，也不请求旧地图接口。设置页不再显示、提交或写入本地默认楼层；后端 `default_floor` 字段、旧地图读取与弹窗保存接口保留兼容，但不影响当前页面。静态导览说明由文件维护。
