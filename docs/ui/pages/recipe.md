# 菜品与食谱 · recipe.html

## 当前视觉与布局 · 2026-10-24

菜谱使用 `.workspace--recipe`：左侧 290px 放三个视图、搜索与数量，右侧显示目录、评价或每周食谱。菜名按字母分组，桌面三列、平板及手机两列，索引保留在右缘。搜索、URL、默认视图和既有评价卡保留；目录新增详情跳转，写评价改为选择已有菜品。全站品牌字标为「拾光酥糕」，详细公共尺寸见 [UI.md](../../../UI.md)。本轮验证结果见 [验收记录](../acceptance.md) 和根目录 [MAP.md](../../../MAP.md)。

> 状态：#4 统一 UI；#5 增加独立目录与三个页签。壳：默认，`data-nav="recipe"`，容器 `workspace--recipe`。

## 视图

| 页签 | 内容 | 操作 |
| --- | --- | --- |
| 全部菜品 `view=all` | 搜索、A–Z 目录、数量与更新时间 | 字母跳转、清除搜索、点击菜名进入详情 |
| 菜品评价 `view=reviews` | 原有图片/菜名/评分/评论/作者/时间卡片 | 登录后写评价，加载更多 |
| 每周食谱 `view=weekly` | 原有按供应日期折叠的上传图片 | 查看大图，有权用户删除 |

明确 URL 优先于账号默认 `recipe_default_view`；无 URL 时读取账号设置，回退 localStorage，再回退 all。用户已经切换后，较晚返回的默认设置请求不会覆盖当前视图。切换取消旧请求并更新 URL，搜索词在各视图间保留。

三个按钮保留 tab 语义及键盘切换，共享内容区为 tabpanel，`aria-labelledby` 指向当前按钮。菜品目录规范见 [dishes.md](./dishes.md)。

2026-10-24：「全部菜品」的菜名统一使用完整系统中文无衬线字体栈与 400 常规字重，避免精简字体缺字导致同一菜名的字形和粗细不一致。保留桌面 14px、手机 13px、原有网格与交互，搜索高亮继承菜名字体；字母索引、计数、评价和每周食谱的字体不变。页面样式资源版本同步更新，验证结果见 [验收记录](../acceptance.md)。

## 评价

列表仍使用 `GET /api/recipes`，评价按原有名称排序，每批二十条；一条评价对应一张卡，图片占位、评分星、评论转义、用户行与原有加载更多均不变。新评价保存已有菜品 ID；旧非每周评价按归一名称补关联，无法匹配的记录仍显示在本栏，不删除或改名。

本页「写评价」入口仍仅在评价页签出现。游客点击显示登录提示；登录后打开与详情共用的对话框，输入菜名、完整拼音或首字母筛选，再从下拉列表明确选择已有菜品；仅输入文字（即使名称完全一致）不能发布，不能新增目录外菜名。修改已选文本即清空选择。支持中文输入法、鼠标、方向键、回车、Escape 与 Tab，加载失败可重试。

候选初始最多显示 50 条（未筛选与筛选后相同），点「显示更多」每次追加最多 50 条，并保留已显示结果、顺序和滚动位置；所有匹配项显示完即隐藏按钮，状态提示总数与已显示数。更换关键词、清空搜索或收起再展开恢复首批。Tab 可进入追加按钮，Enter/空格可追加，离开选菜区域收起；末批按钮消失后焦点回到输入。此规则仅用于写评价时选菜，原评价卡片的每批二十条与分页不变。

评分默认五分，评论与图片选填；评论最多 500 字，JPG/PNG 上限 2 MB。取消或发布失败保留草稿，成功关闭、重置选择与上传并重载本栏。请求向 `POST /api/recipes` 提交 `dish_id`，服务端确定规范名称。完整已有菜名不受旧 20 字计数限制。详情入口与预选行为见 [dish-detail.md](./dish-detail.md)。

钩子：`reviewsBtn`、`writeAction`、`writeBtn`、`reviewDialog`、`recipeForm`、`name`、`selectedDishId`、`dishOptions`、`dishPickerMore`、`comment`、`image`、`recipeSubmit`、`moreBtn`。共用表单由 `public/js/dish-review.js` 在页面初始化时生成。

## 每周食谱

仍使用 `GET /api/weekly-menu` 及已有管理上传/删除接口。按起止日期折叠，本周默认展开；显示上传者与时间，图片可滚轮/双指缩放、拖动和关闭。上传者或 super_admin 以上可删除，操作需要统一确认。

菜单自动同步结果供独立目录使用，不覆盖手动上传的每周图片。无图片显示等待管理员上传，失败提供重试。
