# 首页与关于页 · index.html / about.html

> 当前版本：拾光酥糕 v2.3 · 2026-10-18。视觉依据与尺寸见 [UI.md](../../../UI.md)。

## 首页

`index.html` 使用 `.landing`，通栏 Hero + 最大 1216px 正文；共享顶栏与页脚由 `UI.shell` 生成。品牌为 VC 团队橙子切面的青柠绿色变体图标，中文使用随站加载的 Noto Sans SC。顶栏依次显示「地图、论坛、菜谱、必吃榜、更新公告」。标题固定为「苏州中学最大的」换行「校园信息平台」。桌面标题左下，维护者提供的透明 `public/img/fan-zhongyan-user.png` 右下，渐变为白到绿；手机缩短首屏并缩小插画，确保文字不与雕像相交。

后续区块顺序与参考站相同：居中的关于我们、左文右团队标志的开发团队、左文右折叠项的一起完善、居中校园寄语、三列页脚。开发团队包含橙子切面的 VC 团队标志与依照参考图片简化的软件开发社标志；折叠项提供论坛、评价和工单入口。不引入无依据的用户规模、赞助或运行状态数据。页脚版权固定为「© 2026 苏州中学 VC 编程。」。

## 关于页

`about.html` 恢复独立内容页，介绍平台起源、学生维护、信息来源和反馈方式。首页「了解更多」及页脚品牌链接指向该页。`index.html#about` 保持兼容，定位首页关于段落。

## 行为

- `/` 且无 hash 时保留 `pages/index.js` 的账号默认页跳转；显式 `index.html` 始终展示首页。
- `details/summary` 可用 Enter 或空格展开，一次只展开一项；高度 200ms ease-out 展开/收起、箭头 200ms 旋转，支持连续反向点击。减少动态效果时立即完成；收起内容不进入键盘顺序。
- 桌面首屏高度扣除顶栏与公告实际占高。观察两者尺寸变化，覆盖异步公告、关闭、多行换行与窗口缩放；首页顶栏无分界线，与渐变顶部使用相同背景色。
- 所有入口为真实站内链接，工单和账户页面自行处理登录要求。
- 主题可在顶栏或页脚切换；深色首屏使用 `#14532D` 深绿，并通过 280ms View Transition 平滑变色；减少动态效果模式即时切换。
- 桌面 Hero 底部内距为 32px，标题相较旧版下移 16px；范仲淹像保留用户图像的左上白色高光和深绿背光面，桌面高度约首屏 80%，平板缩为 56%。
- 同源跨文档导航以 420ms 在静止顶栏和公告下方水平滑动，前进向左、返回向右，新旧正文同时可见；公告高度跨页预留，使目标页的顶栏从首帧起就处于正确位置，载入中不闪失。减少动态效果模式直接跳转。
- 顶部后台横幅仍按账号和版本记忆关闭状态，不覆盖后台内容。
