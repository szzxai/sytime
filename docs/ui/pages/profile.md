# 个人中心 · profile.html

更新：2026-10-31。`ProfilePage.tsx` 组合 `ProfileLayout` 与 `SubmissionHistory`。

主页头部以用户名与已批准昵称为主要身份，展示 ID 单独放在低强调辅助行；保留签名、头像与头衔。登录用户名保持独立且不可修改。点击昵称或签名、上传头像、提交展示 ID 变更都产生私有申请；通过前仍展示上一次批准版本，拒绝不覆盖旧资料。展示 ID 为 3–24 位字母、数字或下划线，提交及批准时均检查占用。

主页提供展示 ID 表单、学生身份入口和“我的申请”：按时间分页查看类型、状态、拒绝原因、已发布店铺入口；待审申请可撤回。学生身份按唯一学号绑定，解绑需密码并撤销全部会话。认证通过后需重新登录更新身份。

收藏和头衔保留独立面板；user 只能创建私密收藏，student 及以上可公开。角色变化、解绑或封禁由服务端约束；头像等公开内容不因客户端预览而提前生效。

## 实现与验证

当前实现：React + TanStack Query/Router，Hono + SQLite/Drizzle。权限以数据库当前角色、状态和有效会话为准，隐藏入口不能替代后端校验。验证命令、实测结果与限制见根目录 [MAP.md](../../../MAP.md) 最新记录，以及 [验收记录](../acceptance.md)。

## 2026-10-31 交互修正

头像超过 2 MiB 时在浏览器内压缩后提交，处理中禁用重复选择。本人申请支持 `?submission=<申请号>#home` 精确查看，展示原评论完整文本、状态与拒绝原因；跨页历史也可定位，只能读取本人申请。已通过且仍存在的评价提供对应评论入口；被拒或已删除的评论仍留在私人申请记录中，不对外发布。
