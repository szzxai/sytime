## 入口决定切换关系

主栏目按「首页、地图、菜谱、必吃榜、更新公告」排序。顶栏、移动导航、页脚、账户等正文外入口按这一栏目位置决定方向，详情仍归属于自己的主栏目：菜品属于菜谱，店铺详情与新增店铺属于必吃榜。目标在右侧，新页面从右侧进入、旧页面向左退出；目标在左侧则相反。同一栏目通过站点导航重新进入时使用前进方向，打开默认视图，不执行详情返回。账户类页面继承来源栏目的定位，避免丢失主栏目上下文。

正文内的菜谱→菜品详情、必吃榜→店铺详情/新增店铺按父子关系处理：进入时新页面从右侧出现；返回时详情向右退出，父页从左侧恢复。返回链接在有有效来源时恢复来源 URL、搜索、筛选、排序、分页与滚动位置，并回到原历史条目；直接打开详情、没有来源时仍可返回默认父页。浏览器单步前进/后退沿原导航边恢复或反转方向。

同页分类、搜索、排序与设置标签不触发整页横滑。公告桌面保留并排主从浏览；手机从列表进入正文和返回列表使用父子方向，历史后退/前进保持一致。地图地点卡、弹窗与图片查看仍使用自己的局部交互。

## 意图预加载

站内页面使用 Router Link 的意图预加载。鼠标悬停、键盘聚焦或触摸表达访问意图后准备目标页面，不配置全局 document 点击拦截。离开链接会取消尚未触发的预加载。实际导航与预加载共享页面模块和查询缓存；不因预加载改变地址、切换页面或提交写操作。

菜谱当前视图、菜品详情、必吃榜当前筛选、店铺详情与公告还会准备首批主要数据。默认视图和店铺筛选与页面读取相同账号偏好，避免预加载错误的数据。地图引擎生成的店铺链接由 React portal 承载同样的 Router Link，保留原标记布局和原生链接语义。外部网站、邮件、下载和页内锚点保持原生行为，修饰键打开新标签页不改变当前页。

## 等待与转场

目标代码与首批主要数据准备期间保留当前页面、当前筛选、滚动位置、页脚及共享导航。等待超过 200ms，窗口最上缘显示 3px 的品牌色提示条，可访问名称为「正在加载页面」；快速完成时不闪烁，不遮盖内容，也不增加全屏等待页。

目标就绪后一次提交布局并执行 420ms 横滑。路由归属样式在新快照前更新，普通正文至少占满可用视口高度；地图仍保留自己的全屏高度及隐藏页脚规则，离开地图后再恢复普通壳。滚动恢复直接到目标位置，避免平滑滚动与横滑叠加。慢请求取消后只提交最后一次有效导航。

预加载不等于静态预渲染，也不承诺所有图片、外部地图或后续评论分页在切换前全部完成。次级内容继续沿用局部占位与错误重试；主要请求失败后仍展示现有可重试错误界面。首次打开页面保留加载占位；减少动态效果时直接切换。

## 实现与验证入口

- `apps/web/src/components/SiteLink.tsx`：页面链接与有效来源返回；`MapLinks.tsx` 接入地图链接。
- `apps/web/src/lib/navigation.ts`：栏目归属、父子关系、已呈现位置、查询预加载与路由生命周期。
- `apps/web/src/main.tsx`：可预加载页面、数据加载与稳定提交；`app.css`：正文最小高度和延迟提示条。
- `npm run test:navigation` / `tests/navigation-ui.mjs`：隔离数据，覆盖 360/1280px、明暗主题、键盘聚焦/Enter、鼠标悬停、慢网、页面快照、滚动恢复、主栏目/详情入口差异、浏览器历史、连续选择、失败重试、店铺父子页面、手机公告和减少动态效果。

本轮实际通过项与全量回归限制见根目录 MAP 和 UI 验收记录；不将专项通过等同于全量通过。
