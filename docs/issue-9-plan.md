## 目标

建立统一消息箱，用于接收系统消息及用户互动通知。

> 状态：已实现。前端见 [docs/ui/pages/inbox.md](ui/pages/inbox.md)，变更记录见 [progress.md](../progress.md) 第 50 条。

## 消息类型

### 系统消息

* [x]	管理员/系统发送的通知
* [x]	能显示标题、正文和发送时间
* [x]	明确可发送全局系统通知的最低权限（`announcement_publish`，默认 super_admin）

### 评论相关消息

* [x]	用户评论我的内容（回复帖子时通知楼主）
* [ ]	用户回复我的评论（`forum_replies` 目前为平铺结构、无父评论 ID，暂不产生；补充父子关系后前端按 `type` 自动渲染）

### 点赞相关消息

* [x]	用户点赞我的内容（按目标聚合为「A、B 等 N 人赞了你的帖子《…》」，取消点赞回退聚合）
* [ ]	用户点赞我的评论（当前没有评论点赞表，暂不产生）

### 消息箱

* [x]	消息列表
* [x]	已读/未读状态
* [x]	未读消息数量
* [x]	点击消息进入对应内容
* [x]	支持将消息标记为已读

## 消息设置

- [x] 用户可以决定接收哪些类型的消息：
  * 系统消息（重要通知不可关闭，始终接收）
  * 评论通知
  * 回复通知
  * 点赞通知

## 验收标准

用户能够收到各种消息，并能自行关闭允许关闭的通知类型。评论/回复/点赞开关即时保存；系统消息（含「重要」）始终接收。
