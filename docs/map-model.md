# 校园扫描模型重建

Web 校园地图使用 MapLibre。默认 2.5D 与 2D 共享简化底图。实验性模式渲染扫描重建的墙体、屋面、坡地、桥、驳岸和树冠。地点目录、介绍和侧边栏样式沿用原有页面。

## 简化底图

`overview.ts` 以经纬方向校正建筑轮廓，保留主要院落和分翼，将同一地点的建筑轮廓合并，再扣除道路和步道的绘制范围。所有建筑统一使用 6 米挤出高度。2D 与 iOS 导出使用相同轮廓及道路范围。春雨池北界按标注图中的粉色地块定位，图书馆与尊经阁的路口共用一个控制点。

配色、32° 俯仰、−22° 方位和选中后 650 ms 的视野适配参考 YourTJ-Hub 的四平路校区。本站按校园尺度和右侧信息面板调整聚焦留白及缩放。 [YourTJ-Hub 校园地图源码](https://github.com/YourTongji/YourTJ-Hub/tree/d05b0fbb1eebebf541893cd04882098adec3f0f9/apps/gooseforum/resource/src/site/campus-map)

## 扫描和配准

主要资料为维护者提供的 `苏州中学_LCC.zip`。LCC 5.0 元数据声明 EPSG:32651，本地原点为东距 273410.957 m、北距 3465152.476 m。按 `index.bin` 读取 `data.bin` 的 LOD 2，用不透明度和每个格点的稳定高程层筛选扫描点。在 0.5 m 平面网格上查看低位回波、上表面、俯视色彩和高程剖面。园林建模时，用低位回波辨认地面，并通过现场形状参考区分树冠、亭阁与坡面。

红楼草坪、科学楼、春雨池、碧霞池与尊经阁用于把 `download-3.png` 配准到扫描的米制坐标系，再结合航拍补绘扫描外或遮挡处。原点和校园尺度内的投影近似见 `model.ts`，控制点拟合见 `aerial-model.ts`。地物边缘及高度为人工判读，南区配准来自同一仿射变换下的平面图，不能用于测量、导航或工程。

扫描以北区通道与中部园林为主。两栋红楼、实验楼、科学楼、道山、双池和尊经阁有可用于判读的覆盖。紫阳楼和三元楼的部分屋顶、政道楼及南区建筑、文庙与操场通过航拍和平面图补全。教室内部、地下水底、树丛遮挡的细节和缺失的背立面均为简化表达。详情按地物标注“扫描重建”“航拍补全”或“扫描与航拍”，檐高是地图模型值的近似显示。

## 模型结构

- `scan-model.ts` 用局部米制坐标记录实地判读后的轮廓、檐口与屋脊、门廊、道路、草坪边带、水岸、道山地形剖面和植被。道山主体由 10 × 7 的地面控制网形成连续坡面，路径顺坡抬升，亭阁与树木独立落位。
- `aerial-model.ts` 记录补绘地物，包括体育馆双坡屋面和看台雨棚、来秀坊分层体块、采芹园内院、文庙廊庑、泮池与桥、田径场和周边道路。
- `architecture.ts`、`detail-north.ts` 与 `detail-science.ts` 记录局部尺寸并生成独立的墙、栏板、瓦面、拱砖、门窗和桌凳。
- `model.ts` 生成干净的墙面轮廓、坡屋顶与挑檐、分段曲面、薄面窗带、实体水岸和桥面。扫描包及其影像、原始点云和碰撞网格均留在本地测绘阶段，网站只加载手工重建的几何。
- `survey.ts` 合并建筑、地物、边界和标注坐标。`style.ts` 控制平面图层，`surfaces.ts` 把重建的三角面写入共享深度缓冲。屋面、坡面和桥可直接点选。模式切换保留中心、缩放、方位和选择。
- iOS 通过 `node --import tsx apps/ios/scripts/sync-resources.mjs --map-only` 从简化底图重新渲染离线校园图与地点位置。原生地图通过双指手势同步变换底图与地点触控范围。

`npm run test:map` 验证扫描和航拍地物来源、重建屋面和坡面、两种视图、点选、相机、响应式布局、无障碍及 WebGL 重试。
