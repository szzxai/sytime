## 目标

将店铺详情页修改为两套可切换的页面布局。

## 基本信息区域

- [ ] 显示：
  - 店铺名称
  - 地址
  - 补充位置描述
  - 店铺类型
  - 距离苏州中学的距离
  - 预计步行时间

以下简称“店铺大致信息”。

## 样式一：手机友好模式

参考大众点评类型的纵向结构。

### 页面顺序

1. 店铺大致信息
2. 横向导航栏
3. 菜品
4. 评价

### 横向导航栏

- [ ] 包含：
  - 菜品
  - 评价

功能：

- [ ]	点击“菜品”滚动到菜品区域
- [ ]	点击“评价”滚动到评价区域
- [ ]	页面向下滚动时导航栏保持在页面顶部
- [ ]	用户仍可直接使用滚轮/触摸连续浏览整个页面
- [ ]	当前所在区域可考虑在导航栏中高亮

⸻

## 样式二：电脑友好模式

### 采用左右两栏布局：

左侧：菜品

右侧：评价

### 要求：

- [ ]	两栏能够同时查看
- [ ]	方便边看菜品边查看用户评价
- [ ]	窄屏情况下不能出现严重布局问题

## 用户设置

- [ ] 设置页面中增加“店铺详情页样式”
- [ ]	可选择样式一/样式二
- [ ]	保存用户选择
- [ ]	再次进入店铺详情页时自动使用用户上次选择

## 验收标准

用户可以在两种布局之间切换，并且设置可以持久保存。
