## 资料口径

- **校内补充**：维护者提供各地点的用途与文化背景，并确认墨子馆现更名为政道楼，楼名寓意“文正之道”，致敬诺贝尔物理学奖得主李政道先生，现为北京大学中学物理实验教学中心。2026-10-31 校正教学区域：东紫阳楼由高一、高二共同使用，二楼及三楼部分区域为高二，三楼另一部分区域及四楼为高一，不涉及高三；西红楼为少预班学习区域。这次确认取代此前东紫阳楼仅供高一、西红楼供高二的口径；西紫阳楼仍为高一、东红楼仍为高二教学区域。三元楼教师办公、科学楼行政办公、希文楼面档及泮水居大食堂等其他用途不变。
- **公开资料**：检索学校官网，阅读校史、校园风貌、教学活动、学术交流、心理教育、教工之家及菜单原文；另阅读我苏网转载的校方历史文化介绍。页面中可查阅的引用链接统一登记在 `CampusSources`。
- **引用范围**：来源链接支持相应段落，并不表示链接中的旧文章证明所有现用途。例如年级分配、红楼年代、科学楼1936年始建及量子教育、三元楼命名、道山南园背景、宿舍用途等以维护者补充为依据；不伪称已从对应网页独立核实。旧菜单仅证明餐饮类型，不作为当前菜价或供应承诺。
- **未采用内容**：搜索摘要中未经原文核实的传说、开放时间、收费、房间分配及细节不写入。地图示意不代表实际楼层数、球场数量或通行权限；公共资料中出现的个人手机号不写入地点介绍。
